# A2：姓名匹配

用集合保存姓名，用队列保存候选人的指针，练习容器选择与对象生命周期。编辑并交付 `main.cpp`、`short_answer.txt`。

## 完成后应满足

- 将 `kYourName` 换成用空格分隔的姓名；`get_applicants` 从 `students.txt` 逐行读取姓名，存入集合。
- `find_matches` 找出姓名首字母与目标一致的人，返回保存其姓名指针的队列。
- `get_match` 按自行设计的规则选出一人；没有候选人时返回 `"NO MATCHES FOUND."`。
- 简答涉及有序与无序集合的取舍、姓名哈希方案，以及保存指针的原因和原集合销毁后的影响。

## 编译与检查

在本作业目录执行：

```sh
g++ -std=c++20 main.cpp -o main
./main
```

可以使用 `std::set` 或 `std::unordered_set`，但相关类型必须一致。保留末尾的 `#include "autograder/utils.hpp"`：入口 `main()` 已由它提供，不要重复定义。

源码注释提到的 `utils.h` 是旧文件名；当前辅助文件为 `autograder/utils.hpp`，其中调用处使用 `auto`。README 对空结果说“打印”，函数接口实际要求先返回该字符串。完成简答后清除其中的 TODO；正式提交渠道见原文。
