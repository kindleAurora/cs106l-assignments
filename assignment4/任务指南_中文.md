# A4：拼写检查器

这是结合任务要求与起始代码编写的原创中文任务指南，不是逐段译本。完整要求与教程见[英文原文](README.md)。

## 目标与修改范围

练习用 STL 算法、lambda 和 C++20 ranges 处理文本。只修改并交付 `spellcheck.cpp`；词典、文本显示、距离计算与测试框架已经提供。

## 任务清单

| 接口 | 需要实现的行为 |
| --- | --- |
| `Corpus tokenize(std::string& source)` | 按空白分隔文本，构造带原文位置的 `Token`，去除空 token，返回集合。使用传统 STL 算法。 |
| `std::set<Misspelling> spellcheck(const Corpus& source, const Dictionary& dictionary)` | 用 ranges/views 筛出词典中不存在的词，生成距离恰为 1 的词典候选，丢弃没有候选的结果，返回集合。 |

自己编写的这两个函数不能使用 `for` 或 `while`。调用已有辅助函数即可；不要重写距离算法。仅使用截至 C++20 的功能，不使用 C++23 的 `std::ranges::to`。

## 阅读代码时重点确认

- `Token` 同时保存 `content` 和 `src_offset`，用于把结果标回原文。
- 构造 `Token` 时会自动清理两端标点、空白并转为小写；无需重复实现。
- `find_all` 返回的迭代器包含文本首尾边界。
- 构造 token 的 lambda 必须按引用捕获原字符串；拷贝字符串后，原迭代器就不属于该副本。
- `utils.cpp` 已由 `spellcheck.cpp` 包含，下面的编译命令不再单独添加它。

## 运行与验收

在本作业文件夹打开终端：

```sh
g++ -std=c++20 main.cpp spellcheck.cpp -o main
./main "samplee sentence"
./main
```

最后一条命令启动随附自动测试，需要 Python。自己再检查空字符串、连续空白、两端标点和完全正确的文本。起始代码尚未实现任务，不应期待首次运行就通过。
