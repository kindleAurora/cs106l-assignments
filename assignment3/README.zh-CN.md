## 第 1 部分：创建你的类

发挥你的创造力吧！补全 `class.h` 和 `class.cpp`，创建你自己的自定义类。更多信息请参阅星期二课程中关于类的相关幻灯片。你的类几乎可以表示任何你想表示的事物，只要它满足以下要求。

> [!IMPORTANT] 对类的要求
> 你的类必须：
>
> 1. 有一个接收**一个或多个**参数的自定义构造函数。
> 2. 有一个默认构造函数，也就是无参构造函数。这体现了构造函数重载。
> 3. 有一个或多个私有成员字段，也就是变量。
> 4. 有一个或多个私有成员函数。
>    - 记住，私有函数就像汽车引擎盖下运转的部件！它们是类实现中必不可少的部分，但不应该暴露在公开接口中。试着构思一个在你的类中合情合理的私有成员函数。
> 5. 为某个私有字段提供**至少一个**公开的 getter 函数，即读取函数。
>    - 例如，如果字段为 `int data`，就必须有一个名为 `get_data` 或 `getData` 的函数，其签名如下：
>
>      ```cpp
>      int getData();
>      ```
>
>    - getter 函数还应标记为 `const`。如果不熟悉这一点，请参阅星期四课程中关于 `const` 正确性的内容！
> 6. 为某个私有字段提供至少一个公开的 setter 函数，即设置函数。
>    - 例如，如果字段为 `int data`，就必须有一个名为 `set_data` 或 `setData` 的函数，其签名如下：
>
>      ```cpp
>      void setData(int value);
>      ```

> [!NOTE] 译注：getter 示例中的 `const`
> 上面的 `int getData();` 按原文保留，但原文下一条要求 getter 标记为 `const`。在这个例子中，满足该要求的声明应为 `int getData() const;`。

注意，以上只是获得本作业学分的最低要求。如果你想多加练习，欢迎实现超出这些要求的功能，或者创建多个类！

> [!NOTE] 可选挑战
> 为了多练习、加点印象分，你可以使用星期四课程中讲过的 `template <typename T>` 写法，创建类模板而不是普通类。这完全是可选的！
>
> 注意，如果决定创建类模板，**必须从编译命令中移除 `class.cpp`**。例如，在 Mac/Linux 上，编译命令应为：
>
> ```sh
> g++ -std=c++20 main.cpp -o main
> ```
>
> 还要记得调整文件之间的包含关系，让 `.h` 文件在末尾包含 `.cpp` 文件，就像星期四课程中讨论过的那样。
