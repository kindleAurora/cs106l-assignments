# A3：设计自己的类

自行选择一个对象建模，练习接口、实现分离及 `const` 正确性。编辑并交付 `class.h`、`class.cpp`、`sandbox.cpp`、`short_answer.txt`。

## 设计检查表

- 提供公开的无参构造函数，以及至少接收一个参数的构造函数。
- 至少有一个私有数据成员、一个有实际用途的私有成员函数。
- 至少提供一个公开 getter 和 setter；getter 标为 `const`。命名使用 `getData` / `get_data`、`setData` / `set_data` 这种形式。
- 在 `sandbox.cpp` 的 `sandbox()` 中创建对象；简答说明 `const` 正确性的含义及自己的设计如何满足它。

## 编译与检查

在本作业目录执行：

```sh
g++ -std=c++20 main.cpp class.cpp -o main
./main
```

`main.cpp` 已包含并调用 `sandbox.cpp`，不要把它再次加入编译命令。让 `sandbox.cpp` 能看到 `class.h`；测试器从这里分析类，并查找 `class.cpp` 中对应的成员定义。测试报错中有些提示仍写 `main.cpp`，以实际文件结构为准。

检查测试器源码可知：getter 无参数，返回类型须与对应字段相同；setter 接收一个匹配字段类型的参数，返回 `void`。函数名去掉 `get` / `set` 前缀后，应能对应字段名；用于验收的私有成员不能是 `static`。

初始 `class.h`、`class.cpp` 为空，需要自行设计。类模板是可选扩展，其实现可见性和编译命令不同，做普通类即可完成本题；扩展说明及正式提交渠道见原文。
