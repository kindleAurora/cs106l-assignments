# 开始作业前的准备

原创中文准备指南，非逐句译文。完整安装流程见同目录的 [官方英文说明](README.md)。

目标是让编译器能够生成程序，并让程序调用课程的 Python 测试器。环境检查题本身不要求填写 C++ 答案。

## 准备项目

- Python 3.8 或更高版本：测试器需要它。
- 支持对应标准及标准库功能的 C++ 编译器。设置检查使用 C++23，正式作业的版本见 [中文导航](../README_中文.md)。
- VS Code 可用于编辑与编译。Mac 的官方流程使用 Homebrew GCC，具体可执行文件名应以安装版本为准。

先查看现有工具版本：

```sh
python3 --version
g++ --version
```

你之前使用的是 `/usr/bin/clang++`。Mac 上名为 `g++` 的命令也可能实际指向 Apple Clang，应看版本输出识别；这里尚未替你安装或更换编译器。

## 检查环境

仓库已经下载，无需重复克隆。在终端进入本文件所在的 `assignment-setup` 目录，按官方命令编译和运行：

```sh
g++ -std=c++23 main.cpp -o main
./main
```

这里的 `main.cpp` 会启动测试器。首次执行可能联网安装测试依赖，成功与否应以实际输出为准；本次下载阶段尚未执行。

原说明中的 `assignment0` 是旧路径，本地对应目录实际叫 `assignment-setup`。

完成环境检查后，进入 [A1 中文任务指南](../assignment1/任务指南_中文.md)。
