## 待完成清单

1. 补充所需标准库头文件。
2. 阅读 `Course`：它包含 `title`、`number_of_units`、`quarter` 三个字符串字段。
3. 完成 `CourseDatabase::find_course(std::string course_title)`。把占位返回类型 `FillMeIn` 改成能表达“有课程／无课程”的类型，再按标题查找私有成员 `courses`。
4. 补全 `main()` 中的 `output`。这里要求使用两种 optional 单子操作，不用 `if` 等条件判断来分出查询成功与失败。先比较 `and_then`、`transform`、`or_else` 对参数和返回类型的要求，再决定组合；不要修改题目标记下方的代码。

## 验收与运行

查到课程时，输出格式为：

```text
Found course: <title>,<number_of_units>,<quarter>
```

查不到时，输出：

```text
Course not found.
```

在本作业目录中使用 **C++23** 编译，随后无参数运行测试：

```sh
g++ -std=c++23 main.cpp -o main
./main
```

也可传入一个课程标题单独查询；有空格的标题须放在引号内：

```sh
./main "待查询的课程标题"
```

先完成代码再运行；起始文件故意留有不能编译的占位内容。若编译器不认识 optional 的单子操作，需要检查编译器与标准库的 C++23 支持情况，单改标准选项不一定足够。
