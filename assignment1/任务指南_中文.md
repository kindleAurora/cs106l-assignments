# A1：课程数据整理

练习把 CSV 文本转换成结构体，再分类写回文件。只需编辑并交付 `main.cpp`；`utils.cpp` 提供辅助功能。

## 完成后应满足

- 补齐 `Course`，实现 `parse_csv`、`write_courses_offered`、`write_courses_not_offered`，检查参数传递方式是否能保留调用者需要的修改。
- 读取 `courses.csv` 时跳过表头；`quarter` 为字符串 `"null"` 的记录属于未开课课程。
- 在 `student_output/` 生成 `courses_offered.csv` 和 `courses_not_offered.csv`。每份包含表头；每行按标题、学分、季度排列，逗号旁不添加空格。
- 输出已开课课程后，原容器中只留下未开课课程。

## 编译与检查

在本作业目录执行：

```sh
g++ -std=c++20 main.cpp -o main
./main
```

程序会调用自带测试器。先补齐代码再检查结果；初始模板含有待完成部分。

源码已经包含 `utils.cpp`，编译时不要再单独加入它。官方提交文件为 `main.cpp`，提交渠道及反馈表见原文；自学时可用本地测试结果检查进度。
