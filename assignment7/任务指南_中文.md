# A7：实现独占所有权智能指针

> 这是按任务目标与起始代码整理的原创中文指南，不是全文翻译。完整背景、提示和提交说明见[英文原说明](README.md)。

## 目标与文件

把 RAII、模板、运算符重载和移动语义组合起来，实现管理**单个对象**的 `cs106l::unique_ptr<T>`，再用于链表。此次不要求支持数组。

## 接口清单

在 [unique_ptr.h](unique_ptr.h) 中，保留题目给定接口并完成：

| 部分 | 待完成内容 |
| --- | --- |
| 状态与构造 | 私有数据；接收 `T*` 和 `std::nullptr_t` 的两个构造函数 |
| 访问对象 | `operator*()`、`operator->()`，各有普通版和 `const` 版 |
| 状态判断 | `operator bool() const` |
| 资源管理 | 析构函数；移动构造函数；移动赋值运算符 |
| 限制复制 | 显式删除复制构造函数和复制赋值运算符 |

默认构造函数与 `make_unique` 已提供。题目没有要求新增 `get`、`reset`、`release` 等标准库接口。

在 [main.cpp](main.cpp) 中补全 `create_list(const std::vector<T>& values)`，返回题目自制智能指针管理的链表。节点顺序须与向量一致，空向量对应空链表。`ListNode` 无需修改。

在 [short_answer.txt](short_answer.txt) 中回答四个问题：RAII 的价值、移动后源指针清空的必要性、长链表递归析构的风险，以及此处 `std::move` 的意义。用自己的话说明，不保留答题占位符。
